# Project Overview

This project examines the relationship between COVID-19 vaccination and COVID-19 cases, hospitalizations, and deaths in California. We compared vaccinated and unvaccinated individuals to see how their average COVID-19 rates differed from February 2021 through March 2023.

# How to Run the Code
1. Download or clone the project repository from GitHub.
2. Open the project in RStudio.
3. Make sure the CSV dataset is saved in the same folder as the R Markdown files.
4. Open the R Markdown file you want to run.
5. Click the Knit button in RStudio to run the code and generate the report.
