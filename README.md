# Project Overview

This project examines the relationship between COVID-19 vaccination and COVID-19 cases, hospitalizations, and deaths in California. We compared vaccinated and unvaccinated individuals to see how their average COVID-19 rates differed from February 2021 through March 2023.

# File Descriptions

- **00-requirements.R:** This is an RScript that contains all of the libraries that were used in our project.
- **01-functions.R:** This file is used to explain all the functions we created in this project.
- **Covid-19-Vaccination-Project.Rproj:** This is the folder that we have in our finder, including all of the other files.
- **Covid_project.Rmd:** Contains the data cleaning process, missing-value checks, average rate comparisons, abstract, and executive summary.
- **Data Visualization, Analysis, and Conclusion (STAT107 Project).Rmd:** This contains the original work for visualization, along with the original analysis and conclusion. This was eventually copied into our Final Report.
- **README.Rmd:** Provides an overview of the project files and instructions for reproducing the results.
- **covid19postvaxstatewidestats.csv:** Contains the COVID-19 data used in the analysis.
- **statistical_test.Rmd:** Contains the statistical tests comparing COVID-19 case, hospitalization, and death rates between vaccinated and unvaccinated individuals.
- **statistical_tests.R:** This is the updated version of the statistical tests Rmd, using a function to simplify the old code, and it is sourced in the final project rmd. 
- **Final Report.RMD:** This file contains our whole final report, with all of our data, visualizations, analysis, and contributions.

# How to Run the Code
1. Download or clone the project repository from GitHub.
2. Open the project in RStudio.
3. Make sure the CSV dataset is saved in the same folder as the R Markdown files.
4. Open the R Markdown file you want to run.
5. Click the Knit button in RStudio to run the code and generate the report.
